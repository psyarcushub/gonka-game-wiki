## Code patterns

### State management — Zustand + persist + immer

Доминирующий паттерн в современных TS-идлерах:

```ts
const useGameStore = create(
  persist(
    (set, get) => ({
      coins: new Decimal(0),
      nodes: [],
      lastTick: Date.now(),
      tick: () => set((s) => ({ coins: s.coins.plus(s.income) })),
    }),
    {
      name: 'gonka-save',
      storage: createJSONStorage(() => localStorage),
    }
  )
)
```

Альтернативы: **Valtio** (mutable proxy, Vue-feel), **Redux Toolkit** (overkill для idle), **MobX**.

### Offline progress calculation

Канонический алгоритм:

```ts
const elapsedMs = Date.now() - state.lastSavedAt
const ticks = Math.floor(elapsedMs / TICK_MS)
const offlineGain = state.incomePerSecond.times(ticks * TICK_MS / 1000)
state.coins = state.coins.plus(offlineGain)
state.lastSavedAt = Date.now()
```

Варианты:
- **Clicker Heroes** — без cap
- **AdVenture Capitalist** — pro-rated offline rate (medium = 50% от online)
- **0xVenture-Capitalist**: revenue → Zustand immediately, MongoDB sync every 30s

### Currency formatting (3 уровня)

| Уровень | Library | Когда |
|---|---|---|
| `1.23M`, `4.56B` | **Numeral.js** | до 1e15 |
| `1.23 quintillion` | **swarm-numberformat** | scientific + named |
| `10^^7.5e8` | **break_eternity.toString()** | tetration scale |

Format selector в settings: `Short / Scientific / Engineering / Logarithm`.

### Game tick loop — 3 модели

| Модель | Используют | Trade-off |
|---|---|---|
| **60fps `requestAnimationFrame`** | Antimatter Dimensions, Phaser-based | Smooth, но throttled в background tab |
| **1fps `setInterval`** | Большинство TMA-clones | Простота, hiccups при tab switch |
| **Event-driven + WebWorker** | Idle Forge, IdleTimer.dev | Survives background throttling |

**Best practice (Gonka)**: hybrid — UI ticks 60fps для animations, симуляция в WebWorker @ 10Hz, persist каждые 5 сек.

### Save/load + cloud sync

```
localStorage['gonka:save:v1']        // основной save
localStorage['gonka:save:backup']    // N-1 backup (anti-corruption)
state.version                        // для migrations
```

Cloud sync: debounced upload (30-second batching в 0xVenture-Capitalist).

### Achievement engine

[`react-achievements`](https://www.npmjs.com/package/react-achievements) (npm) — semantic events + react-toastify + localStorage + confetti. Dual license. Альтернатива: catch-all reducer над game events.

## Architecture patterns

### Config-based > entity-based (80% репо)

```ts
// /src/data/nodes.ts
export const NODE_TIERS = [
  { id: 'rtx_3060', baseCost: 100,    baseHash: 1,    costGrowth: 1.15 },
  { id: 'rtx_4090', baseCost: 10_000, baseHash: 50,   costGrowth: 1.20 },
  // ...
]
```

**Преимущество**: balance changes без code redeploy, A/B тесты, легко импортировать из Google Sheets через CSV. The Modding Tree доводит до экстремума — весь геймплей в data files, движок stateless.

### Балансировка через config

**Spreadsheet-driven workflow**: Google Sheets → CSV export → `data/balance.json` → runtime. Antimatter Dimensions хранит формулы (`1.07^Level`) прямо в config, parse при load.

### Сезоны / прогресс

- **Prestige reset** (Antimatter Dimensions, Modding Tree) — обнуление + keeping meta-currency
- **Seasonal config swap** (Hamster Kombat) — `currentSeasonId` в state, server подсовывает свежий balance JSON
- **Era tiers** (Adventure Capitalist) — конфиг с `unlockAtMilestone`

**Для Gonka**: сезон = новый `nodeMarket.json` + `season_bonus_multiplier`, награды конвертируются в perm NFT/badges.

## Конкретные библиотеки для использования

| Назначение | Library | Почему |
|---|---|---|
| Huge numbers | **break_infinity.js** | Drop-in Decimal, 4.5× быстрее decimal.js. Если выйдете за 1e308 — switch на break_eternity |
| Number formatting | **numeral.js** | Industry standard, locale support, custom formats |
| State | **zustand** + `persist` + `immer` | Минимум boilerplate, отличная TS поддержка, persist middleware |
| Animations | **framer-motion** (Motion) | Все TMA примеры используют. `motion.div` + `AnimatePresence` для tap-feedback |
| Number animation | **@react-spring/web** или Motion `useSpring`+`useTransform` | Spring physics дают «money go brrr» feel |
| Charts | **Recharts** (типичные), **Visx** (custom trading-style) | Recharts: до 10k points, declarative; Visx: low-level D3 control |
| TON wallet | **@tonconnect/ui-react** | Официальная SDK, `useTonAddress` / `useTonWallet` hooks |
| TMA SDK | **@telegram-apps/sdk-react** | Современный maintained, `useTelegramMock` для dev outside TG |
| UI kit | **@telegram-apps/telegram-ui** | Native Telegram look — critical для perceived legitimacy |
| Sound | **use-sound** | Lightweight hook, sprite support |
| Achievements | **react-achievements** | Готовое решение (license non-commercial — free) |

## Anti-patterns в open source (что НЕ делать)

1. **Reading wall-clock time без monotonic backup** — exploit: юзер переводит системное время вперёд, claim offline rewards. Mitigation: server-signed timestamp или TON-блокчейн attestation.
2. **`JSON.stringify` Decimal без custom replacer** — теряется precision. break_infinity exports `toJSON()`/`fromJSON()` — используйте.
3. **`setInterval(tick, 16)` без catchup logic** — при frame drops доход недополучается. Pattern: `delta = now - lastTick`, multiply income on delta.
4. **Monolithic component для всех апгрейдов** — встречается в Cookie Clicker / reactclicker. Re-renders бьют по перфу. Solution: selector subscriptions из Zustand + memoized `<UpgradeRow />`.
5. **Save без versioning** — 80% TMA clone-репо. Любое balance изменение ломает saves. Решение: `state.schemaVersion` + migration functions.
6. **Tap event listener без rate-limit** — `tap-mini-app-click` и forks. Cheat-easy автокликерами. Notcoin/Hamster — server-side rate validation.
7. **Hardcoded balance constants по codebase** — Cookie Clicker clones. Решение: central `data/balance.ts`.
8. **Pixel-perfect copying чужих игр (Hamster/Notcoin clones)** — legal risk + commodity. Берите паттерны, не assets.
