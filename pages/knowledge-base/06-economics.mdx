# Модель экономики и инфраструктуры

> Слайд 6 презентации. Откуда деньги, куда тратятся, при каких условиях бизнес выживает.

## Структура затрат

Делится на **фиксированные** (платятся всегда, даже если ноды не работают) и **переменные** (зависят от состояния сетей).

### Фиксированные затраты

| Статья | Что это |
|---|---|
| **Аренда GPU** (ежемесячно) | Видеокарты не покупаются, а арендуются (на этапе R&D — точно). Это снимает риск устаревания железа, но требует постоянных платежей. Серверный GPU = $500-2000/мес на штуку |
| **Хостинг сервера** | Размещение сервера в дата-центре, электричество, охлаждение |
| **Ширина канала** | Интернет-трафик. AI-вычисления могут грузить десятки терабайт в месяц |
| **Стек мониторинга** | Prometheus, Grafana, Alertmanager, логи — серверы + лицензии |
| **Backend инфраструктура** | Серверы Control Plane, базы данных, API |

Эти затраты — **базовая нагрузка на бизнес**. Они есть всегда. Если ноды зарабатывают меньше — бизнес в минусе.

### Переменные затраты (точнее — переменные факторы прибыли)

| Фактор | Влияние |
|---|---|
| **Скорость вознаграждений сети** | Сеть может изменить свою формулу — например, уменьшить выплаты вдвое. Бывает регулярно |
| **Волатильность цены токена** | Токен заработан, но к моменту вывода в фиат — упал на 50%. Это съедает реальный доход |
| **Сложность сети** | Сеть растёт → конкуренция → одна нода даёт меньше вознаграждений (как в bitcoin-майнинге) |
| **Ставка утилизации GPU** | Если карта простаивает (нет задач) — деньги выкидываются на аренду без отдачи |

Это не «затраты» в прямом смысле — это **факторы риска для дохода**. См. [Риски](/knowledge-base/08-risks).

## Модель дохода

Платформа зарабатывает на двух источниках:

### 1. Маржа аренды GPU

> Разница между стоимостью аренды и ценой перепродажи вычислительной мощности.

**Простыми словами:**
- Платформа арендует GPU за $X в месяц.
- Сдаёт игроку (или использует сама) за $Y в месяц.
- Разница Y − X = маржа.

Это та же модель, что у любого reseller-а: купил оптом, продал в розницу.

### 2. Комиссия оркестрации (~5%)

> Применяется к вознаграждениям сети.

**Простыми словами:**
- Нода заработала за месяц 100 токенов.
- Платформа удерживает 5 токенов как комиссию за то, что взяла на себя всю операционку (мониторинг, обновления, перезапуски).
- 95 токенов получает игрок.

Эти две модели работают параллельно: бизнес одновременно получает маржу с аренды и процент с вознаграждений.

## Ключевой KPI

> **Ставка утилизации GPU ≥ 70%**

Это самый важный показатель. Если он падает ниже — экономика рассыпается. Объясню почему:

**Пример с цифрами (условные):**
- Аренда GPU: $1000 в месяц.
- При 100% утилизации нода заработала бы (условно) $2000.
- При 70% утилизации заработает примерно $1400.
- При 70% доход = $1400, расход = $1000 → маржа $400 = 28% от выручки. **Норма.**
- При 50% доход = $1000, расход = $1000 → точно по нулям. **Точка безубыточности.**
- При 30% доход = $600, расход = $1000 → **минус $400 в месяц на каждый GPU.**

Поэтому пороговое значение 70% — это «подушка безопасности» от падения утилизации.

## Метрики (из презентации)

| Значение | Метрика | Описание |
|---|---|---|
| **≥70%** | Требуемая утилизация GPU | Порог устойчивости экономики |
| **95%** | Целевой uptime | Стабильная работа нод |
| **5%** | Комиссия оркестрации | Применяется к вознаграждениям |

## Объектив R&D (первые 90 дней)

**Цитата:**
> Развернуть 1 GPU, измерить реальную ставку вознаграждений, отследить волатильность, рассчитать точку безубыточности, проверить экономическую устойчивость. **Масштабирование запрещено до валидации unit economics.**

**Что это значит:**

Команда декларирует строгую дисциплину: **сначала проверь, что экономика одного GPU сходится, и только потом масштабируй на 10, 100, 1000.**

Это разумно. Распространённая ошибка стартапов — масштабировать «убыточный юнит». Если один GPU теряет $400 в месяц, 100 GPU потеряют $40,000 в месяц. Скорость гибели растёт линейно с масштабом.

Пока не доказано на одном GPU, что:
- утилизация выше 70%,
- uptime выше 95%,
- доход покрывает расход с маржой,

…до этого момента второй GPU **не покупается**.
